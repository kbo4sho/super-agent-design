# Gold Rail Reference

These frames are visual references for the Gold Rail direction. They are not runtime assets and should not be imported into the prototype.

Use them to preserve the intended feel while implementing the UI natively in React and CSS:

- `goal-reference.png`: mandate and setup state
- `run-reference.png`: active execution rail
- `approval-reference.png`: human clearance gate
- `result-reference.png`: settled receipt state

The shipped prototype should remain a native, accessible web UI with light default and a restrained dark theme.
