# Supervised Run

A polished product concept for a lightweight interaction model where a user delegates work to an AI agent while staying oriented, calm, and in control.

The experience demonstrates:

- goal setting
- autonomy selection
- plan review
- supervised execution
- review gates
- approval for consequential action
- final result summary

## Live Site

https://kbo4sho.github.io/super-agent-design/

## Local Development

```bash

npm run dev
```
